# 灵感与案例速记

未成形的教学 idea、看到的案例、课堂里冒出来的想法，先记在这里；成熟后再升级为对应分类目录下的单文件 HTML 讲解页。

## 记录规则

- **按分类分节**，一节一个表格，一行一条；分节顺序与仓库分类体系一致，空分类保留标题。
- 字段：日期 / 标题 / 一句话要点 / 来源 / 可转化方向。
- 「来源」写清渠道（视频号 / 文章 / 课堂 / 学生提问 / 自想），便于回溯。
- 「可转化方向」写下一步动作，让灵感之后能被检索、被利用。
- 单节超过 30 条时按年份拆为 `INDEX-2026.md`，并在本页顶部加链接。
- 文件名一律 ASCII kebab-case；中文内容写在表格里。
