0.4 实验纪律（三条硬要求）

  1. 固定随机种子：所有脚本默认 SEED = 42，改参数可以，改种子必须记录理由。
  2. 标准化只能在训练集上 fit：任何 StandardScaler / PCA 都必须 fit(X_train) 后 transform(X_test)，否则即为数据泄露，本项在评分中直接扣分。
  3. 结论必须有数字支撑：报告中每一句判断都要能对应到结果表中的某个数值。

实验一　SVD 图像压缩与低秩近似

脚本：exp_l1_01_svd.py、exp_l1_02_eig.py ｜ 建议学时：2 ｜ 对应大纲：L1 数学基础

1.1 目的

  1. 理解任意矩阵的奇异值分解 A = UΣVᵀ 及其几何含义；
  2. 用实验验证 Eckart-Young 定理（截断 SVD 是最优秩 k 近似）；
  3. 建立"协方差特征值 λ"与"奇异值 σ"的定量关系 λ = σ²/(n−1)。

1.2 操作步骤

  1. 运行 python exp_l1_01_svd.py，记录 k = 1, 2, 5, 10, 20, 40, 64 时的相对误差与压缩比；
  2. 对比同维度随机高斯投影的误差，确认 SVD 在每个 k 上都更优；
  3. 运行 python exp_l1_02_eig.py，核对自实现 Jacobi 分解与 np.linalg.eigh 的差值；
  4. 打开 results/figures/l1_01_svd_error.svg，观察误差随 k 的衰减曲线。

1.4 思考题

  1. 为什么 k 从 1 增到 5 时画面变化巨大，而 k 从 40 增到 64 几乎看不出差别？
  2. 奇异值衰减速度和数据"有效维度"是什么关系？如果奇异值几乎不衰减，说明什么？
  3. 范例中图像叠加了噪声。为什么 k 较小时重建图像反而更"干净"？这与去噪有什么关系？
  4. 已知 σᵢ² 是 AᵀA 的特征值，请说明为什么用 SVD 实现 PCA 比直接对协方差矩阵做特征分解更稳定。

1.5 常见错误

  • 把 U、Σ、Vᵀ 的维度搞混（经济型 SVD 下 U 为 m×k、Σ 为 k 个值、Vᵀ 为 k×n）；
  • 认为"奇异值越大越好"而不看累积能量比例；
  • 忘记图像矩阵需要先减去均值才是 PCA 意义上的数据中心化。

实验二　PCA 与 LDA 降维

脚本：exp_l3_01_pca.py、exp_l3_02_lda.py ｜ 建议学时：2 ｜ 对应大纲：L3 降维

2.1 目的

  1. 掌握 PCA 的两条等价推导路径（协方差特征分解 / 数据中心化后 SVD）；
  2. 观察主成分数 k 对下游分类精度的影响，理解"方差解释率"如何指导 k 的选择；
  3. 对比有监督降维（LDA）与无监督降维（PCA），验证 LDA 的维度上限为类别数−1。

2.2 操作步骤

  1. 运行 exp_l3_01_pca.py，记录 k = 2, 5, 10, 20, 30, 64 的方差解释率与测试准确率；
  2. 对比"随机高斯投影"对照组，判断 PCA 的优势来自哪里；
  3. 运行 exp_l3_02_lda.py，在 wine（3 类）与 breast_cancer（2 类）上比较 LDA 与 PCA；
  4. 若时间允许，用 common/data.py 的 synth_process 构造 5 维工艺数据，降到 2 维并解释两个主成分的物理含义。

2.4 思考题

  1. 为什么 PCA 之前必须做标准化？举一个不标准化会出错的具体场景。
  2. LDA 最多能降到几维？为什么？这与类间散度矩阵的秩有什么关系？
  3. 实验中"随机投影"在 k 较大时逐渐追上 PCA，这说明什么？

实验三　回归建模与正则化

脚本：exp_l4_01_regression.py ｜ 建议学时：2 ｜ 对应大纲：L4 监督学习

3.1 目的

  1. 对比线性模型与非线性模型在含交互项数据上的表达力差异；
  2. 理解 Ridge（L2）与 Lasso（L1）正则化的不同作用（系数收缩 vs 特征选择）；
  3. 学会用学习曲线诊断过拟合与欠拟合。

3.2 操作步骤

  1. 运行脚本，记录 7 个模型的 RMSE / MAE / R² / 非零系数个数 / 耗时；
  2. 观察"多项式回归（2 阶）"把 5 个原始特征扩到 20 个后的精度变化；
  3. 修改 synth_process 的噪声项幅度（0.18 → 0.5）后重跑，观察各模型的稳健性；
  4. （选做）用 validation_curve 画出决策树深度与 RMSE 的关系曲线。

3.4 思考题

  1. 数据生成式含 62·f² 项，线性模型必然吃亏。若不允许换模型，如何用特征工程补救？代价是什么？
  2. Lasso 的非零系数个数说明了什么？它为何能用于传感器选型？
  3. 为什么本例中正则化带来的精度提升不明显？在什么条件下正则化才会显著提升？
  4. 树模型的 R² 明显更高，是否就意味着工程上应该一律使用随机森林？请从可解释性、部署成本、外推能力三个角度回答。

实验四　分类算法横评

脚本：exp_l4_02 ~ exp_l4_06 ｜ 建议学时：4 ｜ 对应大纲：L4 监督学习

4.1 目的

  1. 在同一数据集上横向对比 KNN、决策树、SVM、朴素贝叶斯、逻辑回归；
  2. 掌握超参数（k、max_depth、C、核函数）对精度的影响规律；
  3. 理解"没有免费的午餐"——模型选择必须结合数据特点。

4.2 操作步骤

  1. exp_l4_03_knn.py：记录 k = 1,3,5,9,15,25 的准确率，以及在 64 / 264 / 864 维（后两者含纯噪声）下的准确率；
  2. exp_l4_04_tree.py：记录 max_depth = 1,2,3,5,不限 时的训练/测试准确率与规则条数；
  3. exp_l4_05_svm.py：在 breast_cancer（近线性）与 moons（强非线性）上比较 linear / poly / rbf 核；
  4. exp_l4_06_naive_bayes.py：比较三种 NB 变体，并在"强相关数据"上观察独立性假设失效的后果；
  5. 把四类结果汇总成一张总表，写出你的选型结论。

4.4 思考题

  1. KNN 在维度从 64 增至 864（新增全为噪声）时准确率如何变化？请解释"维度灾难"的机理。
  2. 决策树深度不限时训练准确率接近 100%，测试准确率反而下降——这个差距在机器学习中叫什么？如何量化它？
  3. moons 数据上 RBF 核远优于线性核，而在 breast_cancer 上差距很小。请从"数据在原空间中是否线性可分"的角度解释。

实验五　聚类与工况分型

脚本：exp_l6_01 ~ exp_l6_03 ｜ 建议学时：3 ｜ 对应大纲：L6 无监督学习

5.1 目的

  1. 掌握 K-Means 的迭代机理与初始化策略的影响；
  2. 理解密度聚类（DBSCAN）为何能处理非凸簇并识别噪声；
  3. 对比硬聚类（K-Means）与软聚类（GMM），学会用 BIC 选择分量数。

5.2 操作步骤

  1. exp_l6_01_kmeans.py：对比 random 与 k-means++ 初始化，记录 inertia 均值与标准差；
  2. exp_l6_02_dbscan.py：在 moons 与 circles 上扫描 eps ∈ {0.1, 0.2, 0.3, 0.5}，记录 ARI、发现簇数、噪声点数；
  3. exp_l6_03_gmm.py：比较 GMM 的四种协方差类型，并用 BIC 扫描 k = 2…6；
  4. （选做）用 synth_process 的 5 维工艺参数做工况分型，解释每一簇的工艺特征。

  1. 为什么 K-Means 必须多次重启（n_init）？k-means++ 解决了什么问题、没解决什么问题？
  2. DBSCAN 的 eps 过小或过大分别会出现什么现象？工程中如何用"k 距离图"选 eps？

实验七　神经网络与特征学习
