# 《人工智能技术及应用》算法大纲

> 定位：面向智能制造/机械类本科生的**应用型** AI 课程。算法教学按"数据 → 降维 → 预测 → 决策 → 深度模型 → 工程落地"递进，每个算法统一用 **六段式** 讲解（直觉 → 数学 → 流程 → 代码 → 调优 → 应用）。

---

## 0. 课程算法地图

| 层级 | 能力 | 代表算法 |
|---|---|---|
| L0 数学工具 | 会算、看懂矩阵语言 | 特征值分解、**SVD**、梯度、凸函数 |
| L1 数据层 | 清洗与表示 | 标准化、独热编码、**PCA**、特征选择 |
| L2 监督学习 | 预测与分类 | 线性回归、**逻辑回归**、决策树、SVM、KNN |
| L3 无监督学习 | 结构发现 | **K-Means**、DBSCAN、层次聚类、GMM |
| L4 集成与优化 | 提精度、会调参 | 随机森林、XGBoost、Adam |
| L5 深度学习 | 端到端建模 | MLP、CNN、RNN、Transformer |
| L6 决策与生成 | 序列决策、内容生成 | Q-Learning、DQN、自编码器、GAN/Diffusion |

**统一教学原则**：先讲"这个算法解决什么工程问题"，再讲数学；每个算法必配一条 `sklearn` 三行代码，让学生当天能跑通。

## 1. 数学基础模块（4–6 学时）

| 知识点 | 要求 | 与后续算法的接口 |
|---|---|---|
| 向量/矩阵运算、范数 | 掌握 | 距离度量、正则项 |
| 特征值分解 A = QΛQ⁻¹ | 掌握 | PCA（协方差法） |
| **奇异值分解 SVD** | **重点掌握** | PCA 数值实现、推荐系统、图像压缩 |
| 梯度与链式法则 | 掌握 | 反向传播 |
| 凸函数与最优化直觉 | 了解 | 梯度下降族 |
| 概率基础：条件概率、贝叶斯、高斯分布 | 掌握 | 朴素贝叶斯、GMM |

### 1.1 SVD（奇异值分解）— 本课程的第一块基石

- **定义**：任意矩阵 A ∈ R^(m×n)，存在 A = UΣVᵀ
  - U ∈ R^(m×m)（左奇异向量，AAᵀ 的特征向量）
  - Σ ∈ R^(m×n)（对角奇异值 σ₁ ≥ σ₂ ≥ … ≥ 0）
  - V ∈ R^(n×n)（右奇异向量，AᵀA 的特征向量）
- **关键性质**
  - σᵢ² 是 AᵀA（或 AAᵀ）的特征值
  - **Eckart–Young 定理**：取前 k 个奇异值的截断 SVD Aₖ = Σσᵢuᵢvᵢᵀ，是原矩阵在 Frobenius/谱范数下的**最优秩 k 近似**
  - 奇异值衰减速度 = 数据的"有效维度"
- **典型应用（教学用 4 个案例）**
  1. **图像低秩压缩**：256×256 灰度图取 k=20，压缩比约 10:1，肉眼几乎无损（最佳课堂演示）
  2. **推荐系统隐语义模型**：用户-物品矩阵补全（Netflix Prize 经典）
  3. **LSA 潜在语义分析**：文本主题提取
  4. **PCA 的稳定实现**：避免直接算协方差矩阵的数值误差
- **课堂演示**：`np.linalg.svd` + 逐 k 重建图像，画出"奇异值能量累积曲线"

## 2. 数据预处理与特征工程（4 学时）

- 缺失值：删除 / 均值中位数填充 / 模型预测填充
- 量纲处理：**标准化 StandardScaler**、归一化 MinMax、RobustScaler（抗 outlier）
- 编码：独热 One-Hot、标签编码、目标编码
- 特征选择：方差阈值、相关系数、递归特征消除 RFE、基于树的重要性
- **工程提醒（易错点）**：Scaler 必须 `fit` 在训练集上再 `transform` 测试集 —— 数据泄露的经典陷阱

## 3. 降维与表示学习（6 学时）★ 重点章节

### 3.1 PCA（主成分分析）

| 维度 | 内容 |
|---|---|
| 目标 | 找一组正交基，使投影后方差最大（= 重构误差最小） |
| 推导路径 | 中心化 → 协方差 C = XᵀX/(n−1) → 特征分解 → 取前 k 大特征值对应特征向量 |
| **与 SVD 的关系** | 对中心化后的 X 做 SVD：X = UΣVᵀ，则 **主成分方向 = V 的列**，**降维得分 = UΣ = XV**，**方差解释率 = σᵢ²/Σσⱼ²** |
| 关键参数 | n_components：整数 或 方差保留比例（常用 0.95） |
| 前置条件 | **必须标准化**，否则方差大的特征主导主成分 |
| 变体 | Kernel PCA（非线性）、Incremental PCA（大数据）、Sparse PCA、Robust PCA |
| 局限 | 只捕捉线性相关；对异常值敏感；主成分物理含义需人工解释 |
| 应用 | 高维工艺参数压缩、传感器信号降维、可视化前置、去噪 |

### 3.2 其他降维/矩阵分解算法

| 算法 | 核心思想 | 适用场景 | 与 PCA 对比 |
|---|---|---|---|
| **LDA** | 最大化类间散度 / 最小化类内散度 | 有标签降维、分类前置 | 监督，最多 C−1 维；PCA 无监督 |
| **NMF** | 非负约束下的矩阵分解 | 图像/频谱分解、可解释部件 | 结果非负，可加性解释；PCA 允许负系数 |
| **t-SNE** | 保持局部邻域概率分布 | 高维可视化（2D/3D） | 非线性、可视化强；不保全局结构、不能变换新样本 |
| **UMAP** | 流形 + 拓扑保持 | 大规模可视化 | 速度快、保全局结构更好；参数敏感 |
| **ICA** | 最大化非高斯性，盲源分离 | 信号分离（鸡尾酒会问题） | 找统计独立分量；PCA 只找不相关分量 |
| **自编码器 AE** | 神经网络非线性压缩 | 非线性降维、异常检测 | 需训练数据量；PCA 是其线性特例（单层线性 AE ≡ PCA） |

> **教学结论句**：PCA/SVD 是"线性最优"，t-SNE/UMAP 是"看得见"，自编码器是"非线性可扩展"。

## 4. 监督学习：回归（4–6 学时）

| 算法 | 核心 | 关键点 | 应用 |
|---|---|---|---|
| 一元/多元线性回归 | 最小二乘 ŵ = (XᵀX)⁻¹Xᵀy | 正规方程 vs 梯度下降；共线性问题 | 工艺参数→零件强度预测 |
| 岭回归 Ridge | 损失 + λ‖w‖²（L2） | 缓解共线性，系数收缩不为 0 | 高相关特征场景 |
| Lasso | 损失 + λ‖w‖₁（L1） | 产生稀疏解 → 自动特征选择 | 特征筛选 |
| 多项式回归 | 特征升维 | 过拟合 vs 欠拟合演示（最佳教学案例） | 非线性响应面 |
| 逻辑回归 | sigmoid + 交叉熵 | **虽叫回归实为分类**；决策边界、概率输出 | 合格/不合格判定 |
| 正则化通论 | 偏差-方差分解 | λ 越大偏差越大方差越小 | 贯穿全课 |

## 5. 监督学习：分类（8–10 学时）

| 算法 | 核心思想 | 数学要点 | 优点 | 缺点 | 典型应用 |
|---|---|---|---|---|---|
| **KNN** | 近邻投票 | 距离度量（欧氏/曼哈顿/余弦）、k 值、归一化必需 | 无需训练、直觉强 | 预测慢、高维失效（维度灾难） | 简单模式识别 |
| **朴素贝叶斯** | 贝叶斯 + 特征条件独立 | P(y\|x) ∝ P(y)∏P(xᵢ\|y) | 小数据快、可解释 | 独立性假设常不成立 | 文本分类、故障工单分类 |
| **决策树** | 递归划分 | 信息增益 / 增益率 / **Gini**；ID3/C4.5/CART | 可解释、可处理非线性 | 易过拟合、不稳定 | 工艺规则提取 |
| **SVM** | 最大化间隔 | 对偶问题、**核函数**（线性/多项式/RBF）、软间隔 C、支持向量 | 小样本强、理论优美 | 大样本慢、概率输出弱 | 小样本缺陷分类 |
| **集成：随机森林** | Bagging + 随机特征 | 双重随机性降低方差 | 抗过拟合、默认参数即好用 | 模型大、解释性下降 | 通用基线模型 |
| **集成：GBDT / XGBoost / LightGBM** | Boosting 串行纠错 | 残差拟合、二阶泰勒展开、正则 | 表格数据 SOTA 级效果 | 调参复杂、易过拟合 | 竞赛/工业主流 |
| **集成：AdaBoost** | 样本权重迭代 | 弱分类器加权组合 | 理论清晰 | 对噪声敏感 | 教学演示 |

> **教学建议**：分类章节用**同一个数据集**（建议 UCI 或学生自己采集的加工数据）跑遍 KNN / 树 / SVM / RF，画决策边界对比图，学生理解最快。

## 6. 无监督学习：聚类（4–6 学时）

| 算法 | 核心 | 参数 | 优点 | 缺点 |
|---|---|---|---|---|
| **K-Means** | 迭代：分配→更新质心 | K、初始化（k-means++）、多次重启 | 简单快、可扩展 | 需指定 K、只适凸簇、对异常值敏感 |
| **K-Medoids / PAM** | 用实际样本点作中心 | K | 抗噪 | 计算贵 |
| **层次聚类** | 自底向上聚合 / 自顶向下分裂 | 距离链接（ward/single/complete）、树状图 | 不需指定 K、可解释谱系 | O(n³)，大数据不可用 |
| **DBSCAN** | 基于密度连通 | ε、MinPts | 自动定簇数、能识别任意形状与噪声 | 密度不均时失效、参数敏感 |
| **GMM + EM** | 高斯混合 + 期望最大化 | 分量数、协方差类型 | 软聚类、概率输出 | 可能局部最优、需初始化 |
| **谱聚类** | 图割 + 拉普拉斯特征分解 | 相似度图、簇数 | 非凸簇有效 | 计算贵 |

**聚类评估**：轮廓系数、Calinski-Harabasz、 Davies-Bouldin；有标签时用 ARI/NMI。**肘部法则 + 轮廓系数**定 K（配合 PCA 二维可视化）。

## 7. 模型评估与选择（贯穿，2–3 学时独立讲）

- 数据集划分：train/val/test、**K 折交叉验证**、分层抽样
- 分类指标：准确率 / 精确率 / 召回率 / F1 / **ROC-AUC** / 混淆矩阵（**强调不平衡数据下准确率失效**）
- 回归指标：MSE / RMSE / MAE / R²
- 偏差-方差权衡 → 学习曲线、验证曲线
- 调参：网格搜索、随机搜索、**贝叶斯优化**（选讲）
- 流水线：`Pipeline` 把 Scaler + PCA + 模型串起来，杜绝数据泄露

## 13. 实验项目清单（建议 8 个）

1. **SVD 图像压缩**：不同 k 值重建 + 压缩比/误差曲线（入门，直观）
2. **PCA 工艺参数降维**：方差解释率碎石图 + 二维散点可视化 + 主成分物理含义解释
3. **回归建模**：加工参数→表面粗糙度，对比线性/Ridge/Lasso/多项式，画学习曲线
4. **分类对比**：同一数据集跑 KNN/决策树/SVM/RF，画决策边界与 ROC 曲线
5. **聚类分析**：K-Means + DBSCAN + 层次聚类对比，轮廓系数定 K
6. **Pipeline 与交叉验证**：完整建模流程，体会数据泄露防治
7. **CNN 缺陷检测**：迁移学习（ResNet18 微调）在工业小样本数据上
8. **综合项目（4 学时）**：自选工业数据集，端到端完成"数据→特征→建模→评估→报告"

## 15. 教学要点速查（教师备忘）

- **SVD 与 PCA 讲透一次，后面反复回扣**（推荐系统、异常检测、AE、LSA 都是它的变体）
- 每个算法必答三个问题：**它解决什么问题？什么时候不能用？比替代方案好在哪？**
- 数学推导控制在"能看懂论文公式"的程度，不追求证明完备
- 全程 sklearn：`fit / transform / predict` 三板斧统一心智模型
- 智能制造场景例子贯穿始终，是本课区别于计算机专业 AI 课的关键
