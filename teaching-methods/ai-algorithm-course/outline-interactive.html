课堂提问点：① 为什么 k 从 1 到 5 变化巨大，而 k 从 40 到 64 几乎看不出差别？—— 答案在能量衰减曲线：奇异值衰减越快，数据"有效维度"越低。② 注意 k 小时画面更"干净"：叠加的测量噪声位于小奇异值方向，被截断 SVD 一并滤掉，这正是 SVD 去噪的原理。

教学要点

  • 定义：任意 A∈Rm×n 可分解为 A = UΣVT，σ1 ≥ σ2 ≥ … ≥ 0
  • σi2 是 ATA（也是 AAT）的特征值；U 是 AAT 的特征向量，V 是 ATA 的特征向量
  • Eckart–Young 定理：截断 SVD 是所有秩 k 矩阵中对 A 的最优逼近（Frobenius 与谱范数意义下）
  • 工程用途：图像压缩、推荐系统隐语义、LSA 主题提取、PCA 的数值稳定实现、伪逆求解、数据去噪

关键提醒：① PCA 前必须标准化，否则量纲大的变量会主导主成分；② PCA 只捕捉线性相关，环形/螺旋结构需用 Kernel PCA 或 t-SNE；③ 主成分的物理含义需要人工解释（例如"第 1 主成分主要反映温度与进给的组合效应"）。

PCA 与 SVD 的关系（板书结论）

对中心化后的数据矩阵 X (n×p) 做 SVD：  X = U Σ V^T
  主成分方向（载荷） = V 的列
  降维得分（投影）   = U Σ  =  X V
  方差解释率         = σ_i^2 / Σ σ_j^2
  ↔ 协方差特征分解法：C = X^T X /(n-1)，C 的特征向量即 V，特征值 λ_i = σ_i^2/(n-1)
  • 两种算法等价，但 SVD 数值更稳定（避免显式计算 XTX 带来的精度损失），sklearn 的 PCA 内部就是用 SVD
  • 单层线性自编码器 ≡ PCA；核 PCA 处理非线性；增量 PCA 处理大数据；Robust PCA 抗异常值

实验一　SVD 图像压缩与低秩近似

脚本：exp_l1_01_svd.py、exp_l1_02_eig.py ｜ 建议学时：2 ｜ 对应大纲：L1 数学基础

1.1 目的

  1. 理解任意矩阵的奇异值分解 A = UΣVᵀ 及其几何含义；
  2. 用实验验证 Eckart-Young 定理（截断 SVD 是最优秩 k 近似）；
  3. 建立"协方差特征值 λ"与"奇异值 σ"的定量关系 λ = σ²/(n−1)。

1.2 操作步骤

  1. 运行 python exp_l1_01_svd.py，记录 k = 1, 2, 5, 10, 20, 40, 64 时的相对误差与压缩比；
  2. 对比同维度随机高斯投影的误差，确认 SVD 在每个 k 上都更优；
  3. 运行 python exp_l1_02_eig.py，核对自实现 Jacobi 分解与 np.linalg.eigh 的差值；
  4. 打开 results/figures/l1_01_svd_error.svg，观察误差随 k 的衰减曲线。

1.4 思考题

  1. 为什么 k 从 1 增到 5 时画面变化巨大，而 k 从 40 增到 64 几乎看不出差别？
  2. 奇异值衰减速度和数据"有效维度"是什么关系？如果奇异值几乎不衰减，说明什么？
  3. 范例中图像叠加了噪声。为什么 k 较小时重建图像反而更"干净"？这与去噪有什么关系？
  4. 已知 σᵢ² 是 AᵀA 的特征值，请说明为什么用 SVD 实现 PCA 比直接对协方差矩阵做特征分解更稳定。

1.5 常见错误

  • 把 U、Σ、Vᵀ 的维度搞混（经济型 SVD 下 U 为 m×k、Σ 为 k 个值、Vᵀ 为 k×n）；
  • 认为"奇异值越大越好"而不看累积能量比例；
  • 忘记图像矩阵需要先减去均值才是 PCA 意义上的数据中心化。

思考题（可展开参考要点）

1. 为什么 k 从 1 增到 5 时画面变化巨大，而 k 从 40 增到 64 几乎看不出差别？
答案在能量衰减曲线：奇异值衰减极快，前几个奇异值已占绝大部分能量（本例前 10 个占 99%）， 剩余奇异值对应的成分主要是噪声与细节，加上去对画面的贡献极小。
2. 奇异值衰减速度与数据"有效维度"是什么关系？若几乎不衰减说明什么？
衰减越快，有效秩越低，可用更少的 k 表示数据；若几乎不衰减（近似均匀）， 说明各方向方差相当、数据近似各向同性（如白噪声），此时低秩压缩会损失大量信息。
3. 为什么 k 较小时重建图像更"干净"？这与去噪有什么关系？
测试图叠加了噪声，噪声能量分散在大量小奇异值方向上；截断 SVD 只保留前 k 个大方向， 顺带滤掉了小奇异值方向的噪声——这就是低秩去噪的原理（工业图像的常见预处理）。
4. 已知 σᵢ² 是 AᵀA 的特征值，为什么用 SVD 实现 PCA 比直接对协方差矩阵做特征分解更稳定？
显式计算 AᵀA 会把条件数平方，放大舍入误差（极端情况下丢失小主成分）； SVD 直接在 A 上做正交变换，数值稳定性更好。sklearn 的 PCA 内部正是走 SVD 路径。

思考题（可展开参考要点）

1. 为什么 PCA 之前必须做标准化？举一个不标准化会出错的场景。
PCA 最大化投影方差，而方差受量纲影响：若一个特征以 mm 计（数值 0.01 量级）、 另一个以 MPa 计（数值 1000 量级），后者会完全主导第一主成分，真正的工艺差异被掩盖。 实验中 wine 数据未标准化时 KNN 准确率仅 0.722，标准化后升到 0.944。
2. LDA 最多能降到几维？为什么？
最多 类别数−1 维。类间散度矩阵 S_b 是 C 个类均值向量的散度， 其秩不超过 C−1，因此非零特征值最多 C−1 个。实验中 wine（3 类）可降到 2 维， breast_cancer（2 类）只能降到 1 维。
3. 随机投影在 k 较大时逐渐追上 PCA，这说明什么？
说明随着保留维度增加，"具体选哪组正交基"变得不那么关键—— 高维下随机子空间已能以较小误差保留大部分成对距离（Johnson–Lindenstrauss 引理）。 但在 k 很小时，主成分方向携带的信息是随机投影无法替代的。
4. PCA 只捕捉线性相关，环形 / 螺旋结构应改用哪类方法？代价是什么？
改用核 PCA（非线性核）、t-SNE / UMAP（流形可视化）或自编码器。 代价：核 PCA 需选核与超参、计算 O(n²)；t-SNE 没有 transform 接口、不能用于特征工程； UMAP 需额外安装且对参数敏感。
